# Kanav Agarwal — Portfolio

Personal portfolio site: research, projects, skills, education, and contact.

Static HTML/CSS/JS with no build step. Open `index.html` in a browser, or serve the folder with any static host (e.g. GitHub Pages).

## Structure

- `index.html`, `research.html`, `projects.html`, `skills.html`, `education.html`, `contact.html` — pages
- `styles.css` — shared styles
- `script.js` — shared behavior (animations, background grid, contact form handoff)
- `images/` — photo
- `resume.pdf` — resume
